# CFP Sources for AI Tools

## CFP Aggregation Platforms

### PaperCall
- **Website**: https://www.papercall.io/
- **Description**: Popular platform for conference CFPs
- **Features**: Search by topic, location, date range
- **AI Relevance**: Many AI/ML conferences use this platform

### Sessionize
- **Website**: https://sessionize.com/
- **Description**: Event content management platform with CFP functionality
- **Features**: Speaker management, session scheduling
- **AI Relevance**: Used by tech conferences including AI events

### Lanyrd (Archive)
- **Website**: https://lanyrd.com/ (archived)
- **Description**: Former conference directory (archive may still be useful)
- **Features**: Historical conference data
- **AI Relevance**: May contain past AI conference information

## Conference Listing Websites

### Conference Alerts
- **Website**: https://www.conferencealerts.com/
- **Description**: Comprehensive conference directory
- **Features**: Search by subject, country, date
- **AI Relevance**: Computer Science and AI categories

### AllConferenceAlert
- **Website**: https://www.allconferencealert.com/
- **Description**: Global conference listing service
- **Features**: Email alerts for new conferences
- **AI Relevance**: AI and Machine Learning categories

### WikiCFP
- **Website**: http://www.wikicfp.com/
- **Description**: Wiki-style conference listing
- **Features**: Community-edited conference information
- **AI Relevance**: Strong AI/ML conference coverage

## Academic and Research Sources

### IEEE Conference Search
- **Website**: https://conferences.ieee.org/
- **Description**: IEEE's official conference directory
- **Features**: Search by society, topic, location
- **AI Relevance**: IEEE Computational Intelligence Society events

### ACM Events
- **Website**: https://www.acm.org/conferences
- **Description**: ACM conference calendar
- **Features**: Search by ACM special interest groups
- **AI Relevance**: SIGAI and other relevant SIGs

### arXiv Conference Announcements
- **Website**: https://arxiv.org/
- **Description**: Preprint server with conference announcements
- **Features**: CS.AI and CS.LG categories
- **AI Relevance**: Major source for AI research conferences
